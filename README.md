AutoVerkauf – Java-Konsolenanwendung

Projektbeschreibung

AutoVerkauf ist ein kleines Java-Konsolenprogramm, das ich entwickelt habe, um meine Kenntnisse in der objektorientierten Programmierung zu verbessern.

Das Programm zeigt eine Liste von Autos an. Benutzer können außerdem ein eigenes Auto zum Verkauf anbieten, indem sie die Marke, die PS-Zahl und die Höchstgeschwindigkeit eingeben.

Funktionen

Anzeige einer Liste mit vorhandenen Autos

Hinzufügen eines neuen Autos über die Konsole

Verwendung verschiedener Konstruktoren für unterschiedliche Angaben

Überprüfung von Automarken und Zahlenwerten

Speicherung von bis zu fünf Autos in einem Array

Verwendete Technologien

Java

Eclipse IDE

Scanner für Benutzereingaben

Programm starten

Das Projekt in Eclipse öffnen oder die Java-Dateien in ein Java-Projekt importieren.

Sicherstellen, dass sich A_Auto.java und A_MAINAuto.java im Package g_Klassen befinden.

Die Klasse A_MAINAuto starten.

Den Anweisungen in der Konsole folgen.

Bekannte Einschränkungen

Das Programm unterstützt maximal fünf Autos.

Ungültige Zahleneingaben werden derzeit mit 0 behandelt. Die Eingabeprüfung soll später verbessert werden.

Die eingegebenen Autos werden nicht dauerhaft gespeichert.
