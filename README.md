# AutoVerkauf – Java Projekt

## Beschreibung
AutoVerkauf ist ein kleines Java-Programm, das ich zum Üben erstellt habe.

Das Programm zeigt eine Liste mit Autos. Man kann auch ein eigenes Auto zum Verkauf anbieten.

## Funktionen
- Autos anzeigen
- Ein neues Auto hinzufügen
- Marke, PS und Höchstgeschwindigkeit eingeben
- Eingaben teilweise überprüfen
- Bis zu 5 Autos speichern

- Scanner für Eingaben

## Verwendete Programme
- Java
- Eclipse IDE

## Programm starten
1. Die Java-Dateien in Eclipse öffnen.
2. Die Klasse `A_MAINAuto.java` starten.
3. Den Anweisungen in der Konsole folgen.
